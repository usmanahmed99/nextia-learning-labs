# Nextia Learning Labs

Jupyter notebooks and starter files for the free courses at [learning.nextia-ai.com](https://learning.nextia-ai.com).

Each lab page on the course site links here with **Open in Colab** and **Open in Kaggle** buttons. You can also download a notebook and run it locally in JupyterLab.

Every notebook is self-contained: its first cell installs what it needs and downloads its own sample data, and states the platforms and date it was last tested. Sample data is synthetic.

Each notebook has a dataset card (`dataset.md`) recording where its data comes from, its licence and why it was chosen. New cards start from [_DATASET-CARD-TEMPLATE.md](_DATASET-CARD-TEMPLATE.md).

Labs are organised by course ID, for example `C04/` for *SQL and Data Preparation for AI*.
