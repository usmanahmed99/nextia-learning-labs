# Deploying AI Models for Real Users

Files for [Deploying AI Models for Real Users](https://learning.nextia-ai.com/courses/serving/).

| Path | Used in | What it is |
|---|---|---|
| [`start/`](start) | Module 1 | The model of *Machine Learning: From Problem to Reliable Model* and the two data files that `make_bundle.py` needs, for learners without their own project from that course. Check the model's SHA-256 first: [start/README.md](start/README.md). |
| [`snapshots/`](snapshots) | Modules 2 to 5, final assignment | The `escalation-service` project as it is at the end of each module. If your project is broken, copy the snapshot of the module that you finished last, and continue from there. [snapshots/README.md](snapshots/README.md) says how. |
| `M06-Lnn-<slug>/` | Module 6 (case studies) | The three case studies: a starter and a finished project as zip files, with an MIT licence, and a dataset card. Complete at least one for the certificate. |

The snapshots do not contain the final assignment's solution.
