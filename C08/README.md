# Building Reliable Applications with LLM APIs

Files for the course [Building Reliable Applications with LLM APIs](https://learning.nextia-ai.com/courses/llm-apps/).

| Folder | What it has |
|---|---|
| [`data/`](data) | The 69-ticket evaluation set, Larkfield's synthetic orders and the support policy, with a [dataset card](data/dataset.md). CC0. |
| [`snapshots/`](snapshots) | The course project `ticket-assistant`: `start` (download it in the lesson *A first run without an account*) and the project at the end of each module. Code MIT, data and recordings CC0. |

You need no account and no key: the project replays recorded model answers. A live model is optional (a free local model through Ollama, or your own key).
