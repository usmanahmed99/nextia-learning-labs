# Changing or cancelling an order

## Cancelling an order

You can cancel free of charge while the order status is Processing.

Once your order has shipped, it cannot be cancelled. You can return it instead.

## Refusing a delivery

If you refuse a parcel at the door, we refund the items when the parcel comes back to us. The original shipping fee is not refunded.

## Changing an order

You cannot add items to an order that has been placed. Place a new order instead.

You can change the address or delivery date while the order status is Processing.

## Returning instead

Go to Orders in your account, choose the item and select Return an item. Or contact the help desk.

We email a return label within 1 business day.
