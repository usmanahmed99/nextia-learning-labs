# Holiday returns extension 2025

## Extended return period

You can return items delivered between 15 November 2025 and 24 December 2025 until 31 January 2026.

This replaces the 30-day window for those items only, when it gives you more time.

## What stays the same

All other rules of the returns policy apply, including those for unused items, items that cannot be returned, and return shipping costs.

## End of this notice

This notice ends on 31 January 2026. After that date, only the returns policy applies.
