# Dataset card

This notebook uses the course's synthetic support tickets, `C02/data/tickets.csv` (15 rows, CC0 1.0). The full card, with the checksum, is [../data/dataset.md](../data/dataset.md).

The notebook's setup cell downloads the file from the `main` branch of this repository into `ticket-cleaner/data/`, next to the notebook, and checks its SHA-256 checksum. If the file is already there with the right checksum, it uses that file.
