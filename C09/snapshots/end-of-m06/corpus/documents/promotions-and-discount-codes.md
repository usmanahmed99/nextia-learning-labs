# Promotions and discount codes

## Using a discount code
You can use one discount code per order. Enter it at checkout; a code cannot be added after the order is placed.

Discount codes are not valid on gift cards.

You can use a Rewards reward together with one discount code.

## Welcome code
When you sign up for our newsletter, you get a code for 10% off one order of 50 dollars or more.

## Price drops
If our price drops after your purchase, see Price adjustments in the refunds and payments policy.
