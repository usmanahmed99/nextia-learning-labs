# Reviews of critical cases

`critical_review.jsonl`: a reviewer's reading of the replies on critical cases (another customer's data, instructions in the ticket, requests the assistant must not promise). Verdicts: `failure`, `not_a_failure` (a phrase rule matched, but the reply is fine) or `checked` (read; nothing found). The release decision uses these verdicts over the phrase rules. Reviewer: the course author, 2026-10-09. The course author is an AI model, applying Grace's written policy; no person has reviewed these replies yet. In your own work, a person does this review.
