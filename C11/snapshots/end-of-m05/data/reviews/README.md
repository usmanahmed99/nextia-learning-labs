# Reviews of critical cases

`critical_review.jsonl`: a person's reading of the replies on critical cases (another customer's data, instructions in the ticket, requests the assistant must not promise). Verdicts: `failure`, `not_a_failure` (a phrase rule matched, but the reply is fine) or `checked` (read; nothing found). The release decision uses these verdicts over the phrase rules. Reviewer: the course author, 2026-10-09.
