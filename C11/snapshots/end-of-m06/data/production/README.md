# Production log (SIMULATED)

`feedback_log.jsonl` is made up for the course: no real usage exists. It is one month (28 days, 1,270 tickets) of Larkfield's assistant in use: the team it chose, the language, whether the agent edited the draft, whether the agent changed `needs_human`, the customer's thumbs (up, down or none) and the topic. A script built it with known effects, so that you can practise finding them: few customers give a thumb and unhappy ones give one more often; a new topic appears in week 3; French tickets grow in week 4. Every row has `"simulated": true`.
