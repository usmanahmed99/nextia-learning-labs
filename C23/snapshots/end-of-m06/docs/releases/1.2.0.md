## ticket-api 1.2.0

- **New for clients:** every classification has `score`, from 0 to 1. `confidence` has the same value and is **deprecated**: it stays until version 2.0, so clients have time to change. History items have `score` too.
- **New, off by default:** classifier `keywords-1.1` (`CLASSIFIER_VERSION=1.1`). On the 33 holdout tickets: accuracy 0.909 (keywords-1.0: 0.636), every must-pass ticket right. We turn it on in production step by step.
- **Database:** migrations replace the table that the app made at start-up. Run `python -m ticket_api.migrate` before the new version starts (Compose does it in the `migrate` service). Migration `002_add_score` adds a column; version 1.1.0 keeps working with it.
- **Owner:** Amira. **Watch after release:** the smoke checks, the error rate in the logs, and `GET /v1/history`, for one day.
- **Rollback:** deploy the 1.1.0 digest. The database needs no change: 1.1.0 ignores the new column.
