# Upgrade a dependency safely

Files for the case study [Upgrade a dependency safely](https://learning.nextia-ai.com/courses/ai-assisted-dev/m06/upgrade-a-dependency-safely/) of the course AI-Assisted Software Development.

| File | What it is |
|---|---|
| `starter.zip` | the project `form-intake` with marshmallow 3.26.2, and the folder `assistant-session`. Start here. |
| `finished.zip` | the same project after the reviewed upgrade to marshmallow 4.3.1, with its tests, README and `DECISIONS.md`. Open it after your own upgrade. |
| `assistant-session/upgrade-marshmallow-4.md` | the recorded assistant session: the exact prompt, the reply and the test results |
| `assistant-session/upgrade-marshmallow-4.patch` | the assistant's change, for `git apply` |
| `dataset.md` | the project card: licence, what is constructed, limits |
| `SHA256SUMS` | checksums of the files in this folder |

Nothing here needs an account or money. `pip` downloads marshmallow from PyPI. The project is MIT-licensed and was written by Nextia Learning for this case study.
