# Fix a bug in an unfamiliar codebase

Files for the case study [Fix a bug in an unfamiliar codebase](https://learning.nextia-ai.com/courses/ai-assisted-dev/m06/fix-a-bug-in-an-unfamiliar-codebase/) of the course AI-Assisted Software Development.

| File | What it is |
|---|---|
| `starter.zip` | the project `delivery-slots` with its Git history and the open issue 12. Start here. |
| `finished.zip` | the same project after the fix: `main` has Amira's two commits; the branch `hana/issue-12` has the maintainers' fix (constructed). Open it after your own fix. |
| `assistant-session/fix-issue-12.md` | the recorded assistant session: the exact prompts, the replies and the test results |
| `assistant-session/fix-issue-12.patch` | the assistant's change, for `git apply` |
| `district_table.py` | the district table: 12 postcodes, one measure for every fix |
| `dataset.md` | the project card: licence, what is constructed, limits |
| `SHA256SUMS` | checksums of the files in this folder |

Nothing here needs an account or money. The project is MIT-licensed and was written by Nextia Learning for this case study.
