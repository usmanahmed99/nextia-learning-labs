# AI-Assisted Software Development

Files for [AI-Assisted Software Development](https://learning.nextia-ai.com/courses/ai-assisted-dev/). The course uses `ticket-cleaner`, the project of [Python for Practical AI Engineering](https://learning.nextia-ai.com/courses/python/), and a coding assistant. You do not need an assistant: every session in the lessons is recorded here.

| Folder | What it is |
|---|---|
| [`snapshots/`](snapshots) | `ticket-cleaner` at the start of the course and at the end of each module. Start with `start`. |
| [`emails/`](emails) | Grace's feature request and her bug report, as she sent them. |
| [`transcripts/`](transcripts) | The recorded assistant sessions: the exact prompts, what the assistant printed, the diffs and the test results. |
| [`candidates/`](candidates) | Six candidate changes for the review practice: three from recorded sessions and three made for the course (constructed). |
| [`data/`](data) | Grace's export from the new web form (also in every snapshot), with its dataset card. |
| [`M06-L01-fix-a-bug-in-an-unfamiliar-codebase/`](M06-L01-fix-a-bug-in-an-unfamiliar-codebase) | Case study 1, [Fix a bug in an unfamiliar codebase](https://learning.nextia-ai.com/courses/ai-assisted-dev/m06/fix-a-bug-in-an-unfamiliar-codebase/): the project `delivery-slots` with its Git history and an open issue, as `starter.zip` and `finished.zip`, the recorded assistant session, the district table and a [project card](M06-L01-fix-a-bug-in-an-unfamiliar-codebase/dataset.md). Code MIT. |
| [`M06-L02-upgrade-a-dependency/`](M06-L02-upgrade-a-dependency) | Case study 2, [Upgrade a dependency safely](https://learning.nextia-ai.com/courses/ai-assisted-dev/m06/upgrade-a-dependency-safely/): the project `form-intake`, moved from marshmallow 3.26.2 to 4.3.1, as `starter.zip` and `finished.zip`, the recorded assistant session and a [project card](M06-L02-upgrade-a-dependency/dataset.md). Code MIT. |

Nothing here needs an account or money. The sessions were recorded with an open-source assistant (Aider) and a hosted model; their cost is in each transcript, so that you know what such a session costs. Reading them costs nothing.

The two case studies use small projects that the course team wrote for them. They are not copies of other projects. The second case study needs an internet connection, because `pip` downloads marshmallow from PyPI.
